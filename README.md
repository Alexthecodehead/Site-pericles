# Raio-X da sua Comunicação — cópia local da página capturada

Esta pasta é uma **reprodução baseada no HTML, CSS, JavaScript, imagens e fontes reais capturados do endereço fornecido** em 19/11/2026, não um redesign.

## Como abrir no Windows

1. Extraia o ZIP inteiro.
2. Execute `abrir-site.bat`. Ele inicia um servidor local usando Python 3 e abre `http://localhost:8000`.
3. Para encerrar o servidor, feche a janela de comando **Servidor local**.

Também é possível publicar a pasta inteira em um servidor web estático. A página principal é `index.html`.

## O que foi mantido

- Textos, seções, layout e estilos de origem (CSS, inclusive animações de rolagem e transições).
- Imagens, depoimentos, foto de Carol, logotipos e fontes capturados localmente.
- Layout para desktop e celular.
- FAQ expandível, zoom dos depoimentos, barras de rolagem dos cards, faixa fixa e cronômetro original.
- Links de checkout, Instagram e chat no fluxo original.

## Ajustes apenas para funcionar como cópia local

- Logotipo e imagens ampliadas passaram a apontar para os **arquivos capturados**, evitando recursos externos quebrados.
- O widget mantém a aparência do original e utiliza seu servidor externo `https://app.benvox.ai` quando há conexão.
- Scripts de pixel do Facebook foram removidos para evitar registrar visualizações e cliques de desenvolvimento nas métricas da pessoa original. Não muda o visual.

## Ligações externas — importante antes de publicar

- **Todos os botões de inscrição ainda apontam para o checkout original:** `https://chk.eduzz.com/D0R8GDKB9Y`. Se alguém comprar sem alteração, a operação ocorre na conta original.
- O chat continua integrado ao serviço externo da marca original (Benvox), não é um chat próprio. Ao clicar, os dados e mensagens podem ir para esse serviço.
- O link do Instagram também continua o original.
- A data/horário do evento, preço e cronômetro (29/11/2026 09:00 horário de Brasília) permanecem iguais.
- Antes de publicar como seu projeto, revise marca, fotos, depoimentos, dados de atendimento, checkout e permissões de uso do material de terceiros.

## Capturas de referência

`referencias/desktop-original.png` e `referencias/mobile-original.png` vieram do capturador. Permitem comparar o visual do site local com o do original.

## Limitação

A captura inclui o front-end, não os servidores da Eduzz, Meta ou Benvox. O comportamento dessas integrações depende dos serviços externos. **Não é uma cópia do backend nem uma garantia de correspondência pixel a pixel em todos os dispositivos/navegadores.**
